# سهمیه و لینک اشتراک

[مستندات](README.md) › سهمیه و لینک اشتراک

## کاربر آزاد یا سهمیه‌ای

هنگام افزودن کاربر (`sudo rovunet users add`) پنل می‌پرسد **آزاد یا سهمیه‌ای**؛ پیش‌فرض «آزاد» است. برای کاربر سهمیه‌ای تعداد **روز** و حجم **گیگابایت** را می‌پرسد و هر دو به‌طور پیش‌فرض آزادند؛ پس می‌توانید فقط زمان، فقط حجم یا هر دو را محدود کنید. `users bulk_add` هم همین محدودیت‌ها را برای چند کاربر یک‌جا می‌پذیرد.

```bash
sudo rovunet users list     # انقضا، سهمیه و مصرف هر کاربر و کاربران متوقف‌شده
sudo rovunet users renew    # برگرداندن کاربر متوقف‌شده: همان لاگین، همان لینک اشتراک، مصرف از صفر
```

- هر ۱ گیگابایت برابر ۱۰۲۴³ بایت است و آپلود و دانلود هر دو شمرده می‌شوند.
- یک تایمر systemd (‏`rovunet-user-expiry.timer`) هر ۵ دقیقه بررسی می‌کند. کاربری که منقضی شده یا کل سهمیه را مصرف کرده **متوقف** می‌شود: دسترسی‌اش برداشته می‌شود ولی لاگین و لینک اشتراکش نگه داشته می‌شود تا `users renew` بتواند برش گرداند.
- عوض کردن رمز کاربر محدودیت‌هایش را حفظ می‌کند و لینک اشتراک جدید می‌دهد.

### چه چیزی شمرده می‌شود

محدودیت حجم فقط روی ترافیکی ممکن است که پنل بتواند اندازه بگیرد. بنابراین کاربر سهمیه‌ای فقط این کانفیگ‌ها را می‌گیرد:

| شمرده می‌شود (به کاربر سهمیه‌ای داده می‌شود) | شمرده نمی‌شود (فقط به کاربر آزاد داده می‌شود) |
|---|---|
| VLESS روی WebSocket | SSH، SSH روی TLS، NaïveProxy |
| VLESS + REALITY و VLESS + XHTTP، تا وقتی آمار آن هسته جواب می‌دهد (‏`sudo rovunet diag` بررسی می‌کند) | تونل‌های DNS، Soar، Hysteria 2، WireGuard |

## لینک اشتراک

هر کاربر، سهمیه‌ای یا آزاد، **یک لینک** دارد که همهٔ کانفیگ‌هایش را حمل می‌کند:

```
https://your-domain/sub/<token>.json
```

آن را در منوی **Subscriptions** اپ بچسبانید. فایل یک فهرست JSON ثابت است که سایت NaïveProxy روی پورت ۴۴۳ سرو می‌کند؛ پس فقط به یک تونل NaïveProxy نیاز دارد. لینک بعد از ساخت کاربر و با `sudo rovunet users configs` چاپ می‌شود.

- لینک خودکار به‌روز می‌ماند: بعد از هر تغییر کاربر یا تونل، بعد از به‌روزرسانی، و برای کاربران سهمیه‌ای هر ۵ دقیقه.
- توکن تصادفی است و لینک قابل حدس نیست؛ مثل خود کانفیگ‌ها محرمانه نگهش دارید.
- وقتی کاربر سهمیه‌ای متوقف شود لینک کانفیگ جدید نمی‌دهد؛ بعد از `users renew` همان لینک دوباره کار می‌کند.

## چند آدرس برای یک سرور

اگر یک آی‌پی سرور مسدود شد، آی‌پی‌های دیگر همان سرور شاید کار کنند. آن‌ها را با فهرست جداشده با ویرگول اضافه کنید؛ اولی آدرس اصلی است (‏`auto` یعنی تشخیص خودکار):

```bash
sudo rovunet config address auto,198.51.100.9
```

لینک‌های اشتراک آن‌وقت هر کانفیگ وابسته به آدرس را به ازای هر آدرس اضافه یک بار می‌آورند تا اپ بتواند به آدرس دیگر برود. هر آدرس اضافه باید واقعاً به همین سرور برسد (آی‌پی روی کارت شبکه یا نام میزبانی که به آن اشاره می‌کند) و پورت‌ها باز باشند. این آدرس اضافه می‌کند، نه لوکیشن. ‏`sudo rovunet config address auto` آدرس‌های اضافه را پاک می‌کند.
