# کاربران و کانفیگ‌های کلاینت

[مستندات](README.md) › کاربران و کانفیگ‌های کلاینت

## مدل کاربر

کاربران **سراسری** هستند: یک نام کاربری و رمز روی همهٔ تونل‌ها کار می‌کند. پروتکل ویژگی تونل است، نه کاربر. هر کاربر می‌تواند هم‌زمان روی همهٔ تونل‌ها احراز هویت شود.

> **هرگز ⁦`root`⁩ یا هر حساب دارای shell را به‌عنوان لاگین VPN ندهید.** کاربران پنل فقط برای forwarding هستند؛ لو رفتن یکی فقط دسترسی تونل را از دست می‌دهد، لو رفتن ⁦`root`⁩ کل سرور را. برای هر نفر، از جمله خودتان، یک کاربر جدای پنل بسازید.

## مدیریت کاربران

</div>

```bash
sudo rovunet users add                              # one user
sudo rovunet users bulk_add --count=50 --prefix=user  # user001…user050, random passwords, up to 500
sudo rovunet users list                             # users and their configurations
sudo rovunet users remove                           # remove a user
```

<div dir="rtl">

به هر نفر کاربر خودش را بدهید تا اگر گوشی‌ای گم شد، فقط دسترسی همان را باطل کنید.

## گرفتن کانفیگ‌ها

| دستور | خروجی |
|---|---|
| ⁦`sudo rovunet users configs`⁩ | همهٔ کانفیگ‌های همهٔ کاربران روی همهٔ تونل‌ها |
| ⁦`sudo rovunet tunnel share <tag>`⁩ | کانفیگ یک تونل؛ می‌پرسد کدام کاربر داخلش باشد |
| ⁦`sudo rovunet tunnel share <tag> --user alice`⁩ | VLESS: لینک‌های ⁦`rovunet://`⁩ و ⁦`vless://`⁩ کاربر alice |
| ⁦`sudo rovunet export-clients --user alice --format rovunet`⁩ | فهرست لینک‌های alice برای اسکریپت؛ ⁦`--annotated`⁩ کنار هر لینک تونلش را می‌نویسد |

در تونل‌های DNSTT، هنگام اشتراک پرسیده می‌شود پروفایل **DNSTT** باشد یا **NoizDNS**. هر دو به یک سرور وصل می‌شوند؛ NoizDNS مقاومت DPI را در کلاینت روشن می‌کند (سخت‌تر شناسایی می‌شود، کندتر است).

کانفیگ حاوی اطلاعات ورود کاربر است. آن را از کانال خصوصی بفرستید، هرگز در گروه عمومی.

## ترتیب کانفیگ‌ها

⁦`users configs`⁩، خلاصهٔ نصب و ⁦`export-clients`⁩ کانفیگ‌های هر کاربر را از سریع‌ترین و مطمئن‌ترین راه ورود تا کندترین فهرست می‌کنند: VLESS روی WebSocket، XHTTP، REALITY، NaïveProxy، SSH over TLS، SSH، بعد پروتکل‌های وابسته به شبکه که UDP هستند یا رمزنگاری ندارند (Hysteria 2، WireGuard، SOCKS5)، و در آخر تونل‌های DNS: کند، ولی در قطعی اغلب تنها چیزی که کار می‌کند. ترتیب ثابت است؛ تست تأخیر خود اپ بعداً آنچه وارد کرده‌اید را روی شبکهٔ شما رتبه‌بندی می‌کند.

## قالب‌های خروجی

| قالب | پیشوند | کاربرد |
|---|---|---|
| بومی | ⁦`rovunet://`⁩ | اپ Rovunet. کل پروفایل، مجموعه (گروه) کاربر و از نسخهٔ v33 اطلاعات ورود را بدون اتلاف، حتی با نویسه‌هایی مثل ⁦`\|`⁩، حمل می‌کند |
| VLESS استاندارد | ⁦`vless://`⁩ | هر کلاینت VLESS (v2rayNG، Hiddify، NekoBox و…)، کنار هر کانفیگ VLESS چاپ می‌شود |
| هستهٔ Xray | ⁦`rovunet://`⁩ (نوع ⁦`xray`⁩)، یا ⁦`vless://`⁩، ⁦`hysteria2://`⁩، فایل ⁦`.conf`⁩ وایرگارد | یکی برای هر کاربر روی هر هسته؛ [هسته‌های Xray](xray-cores.md) را ببینید |
| قدیمی | ⁦`slipnet://`⁩ | نسخه‌های قدیمی اپ؛ همچنان پذیرفته می‌شود |

### مجموعه‌ها در اپ

اپ کانفیگ‌های واردشده را بر اساس سرور و کاربر گروه‌بندی می‌کند، پس همهٔ مسیرهای یک کاربر یک مجموعه می‌شوند. Soar با بک‌اند direct لاگین نمی‌خواهد ولی برای هر کاربر جدا چاپ می‌شود تا در مجموعهٔ همان کاربر قرار بگیرد. کانفیگ‌های هستهٔ Xray هم برای هر کاربر در همان مجموعه چاپ می‌شوند.

## آدرس سرور

کانفیگ‌های SSH over TLS روی پورت خودش، SSH و SOCKS5 آدرس IP سرور را دارند. در سرورهای ابری (Oracle، AWS، GCP، Azure) کارت شبکه فقط IP خصوصی دارد، پس پنل دنبال IP عمومی می‌گردد: IP خود سرور اگر عمومی باشد، وگرنه IP رکورد ⁦`ns.<domain>`⁩ یا دامنهٔ NaïveProxy. اگر هیچ‌کدام پیدا نشد، یک بار می‌پرسد و ذخیره می‌کند.

</div>

```bash
sudo rovunet config address 203.0.113.7   # an IP or hostname, without a port
sudo rovunet config address auto          # detect again
```

<div dir="rtl">

کانفیگ‌های تونل‌های DNS، Soar، NaïveProxy، VLESS و SSH over TLS پشت Naïve با دامنه وصل می‌شوند و به آن وابسته نیستند.

## اپ‌های کلاینت

- **[Rovunet برای اندروید](https://github.com/msVPNco/rovunet-app)** (پیشنهادی): لینک‌های ⁦`rovunet://`⁩ را وارد می‌کند، مسیرهای هر کاربر را در یک مجموعه گروه می‌کند، مسیر انتخاب‌شده را بدون پینگ پیش‌نیاز وصل می‌کند و تست HTTPS جدا از داخل تونل واقعی دارد.
- **کلاینت‌های استاندارد** مثل v2rayNG، Hiddify یا NekoBox: از لینک‌های ⁦`vless://`⁩ و فایل‌های هستهٔ Xray استفاده کنید.
