# Документация Rovunet Panel 2.1.0

[English](../en/README.md) · [فارسی](../fa/README.md) · **Русский** · [简体中文](../zh-CN/README.md)

Rovunet Panel превращает Linux-сервер в многопротокольный сервер доступа. Панель устанавливает каждый протокол как службу systemd и управляет им, создаёт пользователей и печатает для каждого из них готовые к импорту клиентские конфигурации.

## Актуальный релиз: 2.1.0

[Опубликованный релиз](https://github.com/msVPNco/rovunet-panel/releases/tag/v2.1.0) · [Установка v2.1.0 с проверкой SHA-256](../../README.ru.md) · [Официальные изменения и ограничения](../releases/v2.1.0.md)

Версия основана на публичной 2.0.2. Для новой установки действуют следующие значения:

| Протокол | Порт | Изменение |
|---|---|---|
| Shadowsocks 2022 AES-128 — `2022-blake3-aes-128-gcm` | 51820 TCP + UDP | Заменяет WireGuard по умолчанию |
| Классический Shadowsocks AEAD ChaCha20 — `chacha20-ietf-poly1305` | 33444 TCP + UDP | Заменяет TUIC по умолчанию |
| Shadowsocks 2022 AES-256 | 28444 TCP + UDP | Сохранён |
| AmneziaWG | 51840 UDP | Сохранён |

При обновлении заменяемые ядра используют прежние сохранённые порты. Остальные ядра, аккаунты, известный расход и URL подписки сохраняются. Обновите ту же подписку в приложении; два заменённых протокола получают новые данные доступа. Движки остаются привязанными к проверенным подписанным артефактам v2.0.2.

В меню **3 — Users → 2 — Free config (50 GB / 30 days)** создаётся отдельный аккаунт с общим лимитом **50 GiB / 30 дней**. **Users → 3 — Export Free config for review** сохраняет приватный кандидат в `/etc/rovunet/donations/<username>.json`. Экспорт требует исправного учёта и остатка лимита. Все три Shadowsocks-метода исключены из аккаунтов с лимитом трафика. Каталог и вкладка Free в приложениях ещё не опубликованы; этот файл содержит приватные данные доступа.

[CI исходников](https://github.com/msVPNco/rovunet-panel/actions/runs/45071747305), [подготовка](https://github.com/msVPNco/rovunet-panel/actions/runs/45072135345) и [финальная проверка и публикация](https://github.com/msVPNco/rovunet-panel/actions/runs/45076586381) прошли успешно. Финальный подписанный сценарий проверяет установщик `--no-run` и меню обновления официальной **2.0.2 → 2.1.0** в Linux amd64, в изолированных пространствах имён с имитацией systemd. Байты ARM64 проверены, но не выполнялись; частная 2.0.3 не проходила этот сценарий. Проверка не покрывает весь первый интерактивный запуск или живой трафик Caddy/Slipstream. [Полный объём проверки](../releases/v2.1.0-test-scope.txt).

Для установки, новых значений по умолчанию и Free config используйте ссылки выше. Тематические руководства ниже также описывают ранее доступные протоколы; их наличие в справочнике не означает, что они остаются значениями по умолчанию в 2.1.0.

## Соглашения

- Команды выполняются на сервере от root, поэтому показаны с `sudo`.
- `example.com` — ваш домен, `SERVER_IP` — публичный IP-адрес сервера.
- Названия протоколов соответствуют исходным проектам: VLESS, REALITY и XHTTP (Project X), Shadowsocks, Hysteria 2, AmneziaWG, NaïveProxy, SSH и SOCKS5. DNSTT, NoizDNS, VayDNS, Slipstream и Soar — DNS-туннели.
- В панели **туннель** — один настроенный экземпляр протокола с тегом (именем), а **ядро** — управляемый экземпляр протокола, установленный командой `core-install`.
