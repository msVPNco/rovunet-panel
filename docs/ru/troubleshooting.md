# Устранение неполадок

[Документация](README.md) › Устранение неполадок

Начните с `sudo rovunet diag`, затем посмотрите журнал службы нужного туннеля (`sudo rovunet tunnel logs <tag>`).

## Сервер

| Симптом | Вероятная причина | Решение |
|---|---|---|
| Туннель не `active` | Проблема с портом, ключом или конфигурацией | `sudo rovunet diag`, затем `sudo rovunet tunnel logs <tag>` |
| Порт 53 занят | Stub listener службы systemd-resolved | Панель отключает его; если он вернулся: `sudo systemctl disable --now systemd-resolved` и `nameserver 1.1.1.1` в `/etc/resolv.conf` |
| `dig` к серверу завершается по тайм-ауту | Провайдер блокирует входящий UDP/53 | Смените провайдера или используйте протоколы на 443 |
| Let's Encrypt не срабатывает (NaïveProxy) | Запись A ещё не распространилась или закрыт порт 80 | Подождите, откройте порт 80, затем `sudo rovunet restart` |
| Работает только один из нескольких DNS-туннелей | Режим маршрутизации single | `sudo rovunet router status`; переключите через `router mode` |
| `tunnel add` отклоняет TCP-порт | Порт занят другой программой | Выберите другой порт или остановите программу |
| Сертификат отмечен в `tunnel status` | Просрочен, истекает или не читается | Обновите или замените его, затем перезапустите туннель |
| После обновления служба со старым именем | Миграция прервалась | Снова выполните `sudo rovunet post-update`; повтор безопасен |

## Клиент

| Симптом | Вероятная причина | Решение |
|---|---|---|
| Подключается, но трафика нет | Сетевой путь или клиент | Проверьте с сервера: `curl -x socks5h://USER:PASS@SERVER_IP:1080 https://api.ipify.org`. Если там работает, сервер исправен |
| `Connection was reset` | Фильтрация сбрасывает соединение на этом порту | Проверьте `tcpdump -ni any tcp port 8443`, доходят ли пакеты; если нет, пустите туннель через NaïveProxy |
| Пользователь не может войти | Неверные учётные данные или бэкенд | `sudo rovunet users list`; проверьте бэкенд туннеля |
| VLESS подключается, но сайты не открываются | Пользователь удалён или сменил пароль | Выдайте новую конфигурацию |
| «WebSocket upgrade failed» | Путь в ссылке не совпадает с сервером | Выдайте новую конфигурацию |
| Cloudflare 521 / 522 | Cloudflare не достигает сервера | Откройте порт в брандмауэре провайдера |
| Cloudflare 525 / 526 | Неверный режим SSL | Установите SSL/TLS в **Full** |
| Ошибки v2rayNG на VLESS | Включены Mux или XUDP | Выключите Mux; поддерживается только простой UDP |
| Медленный DNS-туннель | MTU слишком велик для пути | `sudo rovunet mtu 1200` (1100 для очень плохих каналов) |
| Пришлось сменить ключ | Старые конфигурации используют старый ключ | `sudo rovunet tunnel edit --tag <tag>`, затем выдайте новые конфигурации |

## Журналы

```bash
journalctl -u rovunet-<tag> -n 200 --no-pager
journalctl -u rovunet-dnsrouter -n 200 --no-pager
journalctl -u rovunet-socks5 -n 200 --no-pager
journalctl -u rovunet-core-<name> -n 200 --no-pager
```
