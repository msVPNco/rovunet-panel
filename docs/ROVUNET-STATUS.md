# وضعیت یکپارچگی پنل و اپ

کلاینت منتشرشده: [Rovunet 0.3.0-alpha06 Full](https://github.com/msVPNco/rovunet-android/releases/tag/v0.3.0-alpha06)، نسخهٔ آزمایشی با امضای debug.

## قرارداد خروجی

قالب rovunet:// می‌تواند فرادادهٔ مجموعه را حمل کند؛ لینک استاندارد VLESS نیز برای کلاینت‌های سازگار ارائه می‌شود. پشتیبانی کلاینت از یک مسیر به معنی استقرار خودکار آن توسط نصب‌کنندهٔ پنل نیست. core-plan برای برنامهٔ استقرار دستی است؛ مدیریت کامل مسیرهای جدید هنوز کار باز است.

## کارهای پیش از انتشار پایدار

- endpoint اشتراک HTTPS و شناسهٔ پایدار سرور/کاربر، مستقل از تغییر IP و دامنه.
- یکپارچه کردن خروجی مسیرهای core-plan با مجموعهٔ همان کاربر.
- تخصیص پورت بدون برخورد Caddy/REALITY روی TCP و HTTP/3/Hysteria2 روی UDP.
- اجرای قرارداد خروجی واقعی پنل و parser اپ در CI و بررسی نتیجهٔ واقعی اجرا.
- آزمون هم‌زمانی چندکاربره، محدودیت منابع و بازیابی سرویس‌ها.

موفقیت اتصال یک کاربر، پایداری برای صدها کاربر یا همهٔ شبکه‌ها را اثبات نمی‌کند. تست گوشی، اشتراک و تعویض مسیر را در [وضعیت اپ](https://github.com/msVPNco/rovunet-android/blob/rovunet/docs/STATUS.md) دنبال کنید.
